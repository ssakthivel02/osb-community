# Community Operations Runbook

## Critical safety incident
1. Preserve evidence and request IDs.
2. Restrict affected content or account using the least disruptive safe action.
3. Escalate child-safety, credible-threat, grooming and imminent self-harm cases immediately.
4. Notify the designated safeguarding and security owners.
5. Record every action in the immutable moderation audit.
6. Do not expose reporter identity to the reported user.

## Abuse surge
Enable rate-limit tightening, pause risky creation endpoints, preserve read access where safe, and activate the moderation backlog alert.

## Moderator compromise
Revoke privileged sessions, rotate credentials, export affected audit events, review enforcement decisions and restore improperly changed content only after evidence review.

## Recovery
Validate tenant isolation, report queues, appeal state, audit completeness and child-safe defaults before reopening writes.
